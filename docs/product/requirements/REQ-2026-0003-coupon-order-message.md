# REQ-2026-0003: Coupons, Unified Orders, Messages

## Requirement

- 优惠券类型：平台券/商家券/活动券/满减券/新人券；领券中心领取，报名结算可用（PRD §17）。
- 统一订单中心：活动订单/体验包订单；状态机 待支付/待参加/进行中/待评价/已完成/已取消/已退款（PRD §29）；支持取消与未核销退款。
- 消息中心：系统/活动/报名/支付/退款/优惠/AI 通知分类，未读角标（PRD §18）；报名成功、支付成功、活动提醒、退款结果产生消息。

## Acceptance

- 满减券不满足门槛时不可选；订单状态派生与操作权限（取消/退款/评价）一致。
