# REQ-2026-0002: Check-in & Review

## Requirement

- 线下活动凭证核销：机构端按凭证码签到（待核销 → 已签到），活动结束确认后订单进入待评价（PRD §11）。
- 活动结束后 C 端「待评价」：综合/体验/教师/环境/服务评分 + 是否推荐 + 图文评价（PRD §21）。
- 评价提交后订单进入「已完成」，评价聚合展示在活动详情；机构不可修改用户评价。

## Acceptance

- 未签到订单不能评价；重复核销/核销已取消订单返回类型化错误。
