# REQ-2026-0001: Family & Activity Registration Loop

## Requirement

- 家长注册登录（mock 手机号 + 验证码），创建家庭并管理多个儿童（昵称/性别/出生日期/兴趣/教育阶段，PRD §3.2/§42）。
- 首页提供搜索、AI 入口（问问知鸭）、快捷入口、推荐活动与热门体验包（PRD §6/§45）。
- 活动中心支持分类（PRD §7.1）与筛选（城市/线上线下/免费/年龄），活动卡片字段完整（PRD §7.3）。
- 活动详情展示基础信息、活动内容、机构信息、评价与底部操作（收藏/分享/联系机构/立即报名，PRD §8）。
- 报名流程：选择儿童 → 选择场次 → 选择优惠券 → 确认订单 → 支付 → 报名成功（订单号 + 凭证 QR，PRD §9）。
- 系统自动检查：年龄适配、名额、重复报名、时间冲突（PRD §9.2）。

## Acceptance

- 无儿童/名额满/年龄不符/重复报名/时间冲突时给出明确错误且不产生订单。
- 支付成功后订单进入「待参加」，生成凭证码与 QR。
