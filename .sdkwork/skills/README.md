# Repository-Local Skills

Agent skills scoped to `sdkwork-zhiya` live at
`.sdkwork/skills/<skill-name>/SKILL.md` with lowercase kebab-case names.

This repository has no repository-local skills yet. Global skills follow the
platform skill discovery rules and are not stored here.

Skills never contain source code, secrets, or runtime data
(`../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`).
