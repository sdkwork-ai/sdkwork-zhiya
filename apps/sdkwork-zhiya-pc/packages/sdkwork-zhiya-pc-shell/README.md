# Zhiya PC Shell

`@sdkwork/zhiya-pc-shell` — desktop navigation chrome for the Zhiya PC
surface (APP_PC_ARCHITECTURE_SPEC.md): fixed 240px navigation rail with the
five cross-surface tabs (首页/活动/AI/商城/我的), unread badge, session
footer, and the brand strip. Layer role: `frontend-shell`.

Verification: `pnpm --filter @sdkwork/zhiya-pc-shell typecheck && pnpm --filter @sdkwork/zhiya-pc-shell test`
