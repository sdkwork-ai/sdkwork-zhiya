# @sdkwork/zhiya-intent-core

Activity vocabulary + rule-based zh-CN intent recognizer for 问知鸭
(PRD §14, §32). Pure functions, zero dependencies: age ("8岁"), budget
("预算100元"), categories ("亲子活动"), education directions ("编程/科学"),
mode ("线上/线下"), free demand ("免费"), time ("周末"), and experience-plan
demand ("计划").

Verification: `pnpm --filter @sdkwork/zhiya-intent-core test`
