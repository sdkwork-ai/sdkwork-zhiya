## SDKWORK Soul

Agent execution follows `../../../sdkwork-specs/SOUL.md`: specs before memory, dictionary before context, evidence before completion, stop on ambiguity.

## SDKWORK Standards

Use `../../../sdkwork-specs/README.md` and `../../../sdkwork-specs/AGENTS_SPEC.md` as the global authority. Repository entrypoint: `../../AGENTS.md`.

## Application Identity

App surface: `sdkwork-zhiya-mini-program` — the WeChat mini-program client of Zhiya (知鸭). Domain `zhiya`; five native tabBar pages (首页/活动/AI/商城/我的) projected from the cross-surface route identities; the C-end flow (报名/支付/订单/评价/家庭/消息) lives in the `detail` subpackage. The org workspace is not part of the mini-program surface (merchants use PC/H5).

## Local Dictionary Structure

- `packages/sdkwork-zhiya-mp-*` — TypeScript capability packages; they never call `wx.*` — the typed host adapter boundary lives in `src/bootstrap/runtime.ts`.
- `src/pages/` + `src/detail/` — native WeChat pages projected from route contributions, authored in TypeScript (`index.ts`) under the `MINI_PROGRAM_APP_ARCHITECTURE_SPEC.md` §1 language boundary; the platform `index.js` beside them is generated by `scripts/build-runtime.mjs` and must not be hand-edited.
- `src/runtime/` — generated committed artifacts produced by `scripts/build-runtime.mjs`: the esbuild CommonJS bundle of `src/bootstrap/runtime.ts` (`app.js`), its typed surface (`app.d.ts`, re-exporting `PageApi`), and the profile-stamped `runtime-env.js`.
- `config/mini-program/` — per-profile runtime-env sources; `etc/` — the deployment index.

## Code Style Rules

All authored sources in this root are TypeScript (strict family per `tsconfig.json`); platform `.js` files are generated output only. UI pages bind data and events only; all domain logic flows through the bundled runtime (`appApi`, typed via `src/runtime/app.d.ts`). Shared domain logic lives in the common service family (`@sdkwork/zhiya-service-core` et al.) — never duplicated into the packages here. `src/index.ts` is each package's only public export boundary.
